# Generated Flutter plugin files — leave them alone

These files are regenerated by Flutter on every `flutter pub get` / `run` / `build`. Photo Quest targets Android and iOS only, so they are noise.

```text
linux/flutter/generated_plugin_registrant.cc
linux/flutter/generated_plugins.cmake
macos/Flutter/GeneratedPluginRegistrant.swift
windows/flutter/generated_plugin_registrant.cc
windows/flutter/generated_plugins.cmake
```

They are marked `skip-worktree` locally, so git hides their changes. Rules:

1. Never edit, `git add`, commit or `git restore` them. Never use `git add -A` / `git commit -a` without confirming these are not included; stage files by path.
2. Do not mention them in change summaries or treat them as "unrelated changes to clean up".
3. If a merge/pull/checkout fails because of them, run:
   `git update-index --no-skip-worktree <files>`, `git restore <files>`, finish the operation, then set `--skip-worktree` again.
4. If `git ls-files -v` shows them with `S` the flag is on. If it shows `H`, re-run:
   `git update-index --skip-worktree <the five files>`.
   The flag is local to this clone; a fresh clone needs it once.
